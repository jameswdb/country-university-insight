# country-university-insight

输入一个国家，产出该国 TOP 高校的教授/研究人员图谱：可筛选的合并主库（Excel）+ 每校一份 PDF 深度报告 + 多校对比报告。

从「以色列十校教授研究图谱」项目沉淀而来（31,765 条记录、11 份报告、36 个字段的实战验证）。

## 安装

```bash
# 解压到技能目录
unzip country-university-insight.zip -d ~/.agents/skills/
# 或
unzip country-university-insight.zip -d ~/.claude/skills/
```

重启会话后，技能列表里会出现 `country-university-insight`。

## 使用

直接说：

> 帮我做一下日本 top 10 大学的教授研究图谱

技能会依次问你三件事（不会替你决定）：

1. **范围** —— 国家 + 学校数量；发现出来的学校清单会先给你确认
2. **凭据** —— `OPENALEX_API_KEY`（必需）、`S2_API_KEY`（可选）、GitHub token（仅上传时需要），分别输入，只放在环境变量里
3. **是否上传 GitHub** —— 单独确认仓库名与可见性

## 产出

```
insight/
├── docs/<country>_master.xlsx     合并主库（每校 + 全量 + 领域矩阵 + 专门化 + 主题迁移）
├── reports/<CODE>_report.pdf      每校 12–14 页
├── reports/00_overview.pdf        多校对比
└── scripts/                       16 个脚本，全流程可复现
```

## 单校报告结构

1. 封面四指标（研究人口 / A 层 / 集中度 / 五年增长）
2. 执行摘要（规模与集中度、学科专门化、PI 信号、新锐）
3. 方法与校验（人员口径、**官方名录可得性核查表**、分层规则、误差）
4. 全校产出与结构（年度曲线、类型、OA、主题前 12、合作国）
5. 学科结构（领域规模、专门化指数、分层×领域、各领域前 5 人）
6. 研究主题十年迁移（相对份额 + 绝对产出 + 热力图）
7. 人（十年产出 / 近三年 / 新锐 / 代表作与影响力引用 / PI 指数）
8. 在多校中的位置
9. 局限
10. 附录（数据源、字段字典、多校对比总表）

## 指标口径（重要）

| 指标 | 定义 | 陷阱 |
|---|---|---|
| A 层 | 发表跨度 ≥12 年 且 ≥12 篇 | 推断，不是职称 |
| 署名次数 | 人-篇，一篇多作者重复计 | 与「机构论文数」不同量纲，不可相减 |
| PI 信号 | 被引前 100 篇的末位作者比例 | 大合作组（ATLAS/CMS）按字母序署名会失真 |
| 集中度 | A 层前 10% 的产出份额 | 区分「少数大 PI 型」与「均衡型」 |
| 专门化指数 | 本校领域份额 ÷ 多校均值 | >1.3 为特色强项 |

## 合规边界

- **不使用 LinkedIn**：无凭据，且其用户协议禁止自动化访问；职业轨迹用 ORCID 公开 API
- **不绕过 CRIS/Cloudflare**：探测到 403 就记「不可得」，写进报告的名录核查表
- **不美化推断**：A/B/C 与 PI 都标明是推断

## 数据源

| 源 | 用途 | 是否需要 key |
|---|---|---|
| OpenAlex | 作者、主题、逐年产出、机构聚合 | 建议有（无 key 额度只够 1–2 校） |
| ORCID | 现职、任职经历、学历 | 否 |
| Semantic Scholar | 影响力引用、代表作 TLDR | 是（免费申请） |
