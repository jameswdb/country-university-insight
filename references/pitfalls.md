# 踩坑清单（实战验证，动手前必读）

## API 与字段

1. **OpenAlex 没有 cursor 分页权限时**：用 `page=` + 按 `works_count` 分桶，避免触到 10,000 条的翻页上限。
2. **Semantic Scholar `tldr` 不在 `/author/{id}/papers` 的合法字段里**，传了直接 400。
   TLDR 要用 `/paper/{id}?fields=title,tldr` 单独取（每人只取代表作 1 次）。
3. **S2 无 key 的共享池基本不可用**：实测 10 次请求只成功 1 次，约 10 分钟/人。必须用 key（1 req/s）。
4. **S2 的 `influentialCitationCount` 只在 paper 级存在**，author/search 里传会 400。
5. **ORCID 的 `organization-address.country` 常为空**，别指望用它做国别分析；机构名才是可靠字段。
6. OpenAlex 的 `counts_by_year` 必须显式 `select`，否则缓存里没有，会导致所有年份为 0。

## 计数口径（最容易写错的地方）

7. **“机构论文数” ≠ “研究人口署名次数”**。前者按篇，后者按人-篇，一篇多作者会重复计。
   魏茨曼案例：机构 2.4 万篇，A 层署名次数 14.6 万。若写成“可归属论文 14.6 万篇”就是错的。
8. 大合作组（ATLAS/CMS）单篇上千作者，个人署名次数可到数千——必须分列，不能直接排名。
9. 2026 年收录不完整（滞后 3–9 个月），所有年度/峰值结论用 2016–2025。

## PDF / DOCX 排版

10. **LibreOffice 不认 `w:tcW`，只认 `w:tblGrid/w:gridCol`**。只设单元格宽度，表格会按等宽渲染，
    长文本列被压成 3 行、表格串页。必须同时写 gridCol 的 `w:w`（twips）和 `tblW`。
11. 表格总宽超过版心（如 16.4cm）会触发整体重排；所有 `widths` 之和要 ≤ 版心宽。
12. 段落级分页符（`doc.add_page_break()`）在章节中间容易产生空白页；用“标题 keep_with_next + 内容自然流”更稳。
13. 图片宽度超过版心会挤出空白页；先用 12cm 左右，页数不够再靠**内容**补，不要靠放大图。
14. 页数目标（如 12–14 页）要用**真实内容**补（名录核查表、主题全景、领域前 5 人、附录对比表），
    不要用空行或放大字号凑。

## 抓取与合规

15. **LinkedIn 不可用**：无凭据，且用户协议禁止自动化访问。职业轨迹用 ORCID 公开 API。
16. 多数高校 CRIS（Pure）有 Cloudflare 防护且需机构 key；探测到 403 就记录“不可得”，不要尝试绕过。
17. 只有极少数学校（如 TAU）有可批量抓取的公开通讯录；其余必须走 OpenAlex 推断并**在报告里标注**。
18. 学校官网的“faculty/staff”页经常 404 或返回验证码（Radware）；探测结果要如实写进“名录可得性核查表”。

## 工程

19. 所有下载脚本必须**断点续跑**（state 文件 / JSONL 缓存），否则一次限流就前功尽弃。
20. JSONL 逐行 append + flush，进程被杀也只丢当前一条。
21. 领域分类用**词首锚定正则**（`(?<![a-z])art`），否则 `art` 会命中 `particle`。
22. 子进程调 LibreOffice 转 PDF 时，输出文件必须先删再转，否则会读到旧文件误判成功。
23. 校验 PDF 用文件头 `%PDF-` + 页数，不要只看文件存在。

## 数据质量抽查（交付前）

24. 高产出榜前 20 名逐个人工看“姓名 + 主题 + 机构”是否自洽（发现过同名不同人、跨领域误配）。
25. A 层里若 ORCID 现职显示“Postdoc”，说明分层偏松，这是**下界**，报告要写明而不是隐藏。
