# 方法论：从国家到教授图谱

## 1. 人员口径（决定一切）

| 口径 | 适用 | 得到什么 | 得不到什么 |
|---|---|---|---|
| 官方名录（如 TAU 的 אלפון） | 学校有可批量抓取的公开通讯录 | 真实职称、院系、联系方式 | 仅少数学校可用 |
| OpenAlex 署名作者 | 其余全部 | 姓名、论文、主题、逐年产出 | 职称、院系、任职年限 |

OpenAlex 口径的操作定义：`last_known_institutions.id = 学校` 且 `works_count ≥ 6` 的作者。
`≥6` 这个门槛用于剔除访问学生与一次性合作者；它不是“教授”的定义。

**两种口径的人数不可相加或直接比较**，因为官方名录包含不发表论文的教师，而 OpenAlex 只含发表者。

## 2. 分层规则（推断，不是职称）

| 层 | 规则 | 含义 |
|---|---|---|
| A | 发表跨度 ≥12 年 且 ≥12 篇 | 研究型教席（含资深研究员、临床教授） |
| B | 跨度 ≥9 年 且 ≥8 篇 | 可能为教席 |
| C | 其余 | 多为博士生、博士后、访问学者 |

校验方式：抽 100 位 A + 20 位 C，比较“末位作者比例”（PI 信号）。
实战结果：A 层中位数 0.16–0.33，C 层 0.00–0.10，说明分层确实区分了 PI 与早期研究者。
但 A 层会混入少量资历较长的博士后——用 ORCID 现职做下界估计，不要宣称精确。

## 3. 指标定义

| 指标 | 定义 | 注意 |
|---|---|---|
| `works_10y` | 近十年**署名次数**（人-篇，一篇多作者重复计） | 与机构论文数不同量纲 |
| `works_2016_2020` / `works_2021_2026` | 前后五年 | 用于增长对比 |
| `works_2024_2026` | 近三年 | 判断“现在是否还活跃” |
| `span` | 首篇到末篇的年跨度 | 来自 `counts_by_year` |
| `last_share` | 被引最高 100 篇中的末位作者比例 | 大合作组学科会失真 |
| 集中度 | A 层前 10% 的产出份额 | 区分“少数大 PI 型”与“均衡型” |
| 专门化指数 | 本校某领域产出份额 ÷ 多校平均份额 | >1.3 为特色强项 |
| 新锐 | 近三年速度 ≥1.8× 前五年 | 只是加速，不等于质量 |
| 影响力引用 | Semantic Scholar `influentialCitationCount` 之和 | 需 S2 key；抽样上限 100 篇 |

## 4. 主题迁移

对比 2016–2020 与 2021–2026 两个窗口，**扣除全校总量增长**后算相对份额变化：

```
relative_growth = ((late+5)/late_total) / ((early+5)/early_total) - 1
```

只统计两个窗口各 ≥15 篇、且都进入 OpenAlex 前 200 主题榜的主题（可比子集，不是全部主题）。
`+5` 是平滑，避免小样本除零。

## 5. 校验

1. **PI 对照**：A 层 vs C 层末位作者比例。
2. **公开名单抽查**：找得到院系教席名单的学校（如 Technion 物理系 38 人），算 A 层召回率。
3. **ORCID 现职**：A 层中明确标注“博士后”的比例，作为精度下界。
4. **主题一致性**：高产出者的人均主题是否与其领域一致（发现跨领域误配）。

## 6. 报告章节（单校 12–14 页）

1. 封面（研究人口 / A 层 / 集中度 / 五年增长）
2. 执行摘要（4 个判断：规模与集中度、专门化、PI、新锐）
3. 方法与校验（人员口径、**官方名录可得性核查表**、分层与 PI、误差）
4. 全校产出与结构（年度曲线、类型、OA、主题前 12、合作国）
5. 学科结构（领域人数/产出、专门化指数、分层×领域、各领域前 5 人）
6. 研究主题十年迁移（上升/下降、绝对产出表、热力图）
7. 人（6.1 十年产出 / 6.2 近三年 / 6.3 新锐 / 6.4 代表作与影响力引用 / 6.5 PI 指数）
8. 在多校中的位置（排名表 + 位次句）
9. 局限
10. 附录（数据源、字段字典、多校对比总表）
